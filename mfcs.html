MODULE I • Mathematical Logic

Basic Logic

Statements & Notations

A statement is a declarative sentence that is either true or false, but not both. Usually represented by p, q, r.

Example: p: “5 is odd.” → True.

Logical Connectives

NOT (¬p), AND (p∧q), OR (p∨q), implication (p→q), and biconditional (p↔q).

p→q is false only when p is true and q is false.

Well-Formed Formula

A formula constructed according to the syntax rules of propositional logic is a well-formed formula (WFF).

Truth Tables

Truth tables list all possible truth-value combinations and the resulting value of a compound proposition.

Tautology

A compound proposition that is true for every possible assignment of truth values.

p∨¬p is a tautology.

Logical Equivalence & Implication

Two propositions are logically equivalent when they have identical truth values in every row. p logically implies q when p→q is a tautology.

Normal Forms

DNF: OR of AND terms. CNF: AND of OR terms. Principal forms use minterms/maxterms.

MODULE II • Predicate Logic & Relations

Predicate Logic

Inference in Statement Calculus

Inference determines whether a conclusion follows from given premises. Truth tables can be used to test validity.

Rules of Inference

Common rules include Modus Ponens, Modus Tollens, Hypothetical Syllogism and Disjunctive Syllogism.

Modus Ponens: p→q, p ⟹ q

Consistency & Indirect Proof

A set of premises is consistent if there is at least one assignment making all premises true. Indirect proof assumes the opposite and derives a contradiction.

Predicates & Quantifiers

A predicate contains variables. Universal quantifier: ∀. Existential quantifier: ∃.

∀x P(x): P is true for every x.   ∃x P(x): P is true for at least one x.

Free & Bound Variables

A variable controlled by a quantifier is bound. A variable not controlled by a quantifier is free.

Universe of Discourse

The universe of discourse is the set of objects over which variables in a predicate statement are allowed to range.

Binary Relations

Study properties such as reflexive, symmetric, antisymmetric and transitive relations, with examples.

Equivalence & Partial Order

An equivalence relation is reflexive, symmetric and transitive. A partial order is reflexive, antisymmetric and transitive.

Transitive Closure & Compatibility

Transitive closure adds the pairs needed to make a relation transitive. Compatibility describes preservation of relation structure under the relevant operation/mapping.

Hasse Diagram

A Hasse diagram represents a finite partially ordered set by omitting loops and transitive edges and using upward edges for larger elements.

Lattices

A lattice is a partially ordered set in which every pair of elements has a greatest lower bound (meet) and least upper bound (join).

MODULE III • Functions & Algebraic Structures

Functions

Inverse Function

An inverse reverses the mapping. A function has an inverse function when it is bijective between the relevant sets.

f⁻¹(f(x)) = x and f(f⁻¹(y)) = y.

Composition of Functions

Composition applies one function after another.

(f∘g)(x) = f(g(x)).

Recursive Functions

A recursive function is defined using smaller instances of itself, together with a base case.

Algebraic Systems

An algebraic system consists of a non-empty set together with one or more operations defined on it.

Semigroup & Monoid

A semigroup has an associative binary operation. A monoid is a semigroup with an identity element.

Group & Subgroup

A group has closure, associativity, identity and inverse for every element. A subgroup is a subset that itself forms a group under the same operation.

Homomorphism

A homomorphism preserves the operation between algebraic structures.

f(a*b) = f(a) * f(b).

Isomorphism

An isomorphism is a bijective homomorphism. It shows two algebraic structures have the same structure.

MODULE IV • Counting Techniques

Counting

Basic Counting

Use the addition rule for alternatives and multiplication rule for successive choices.

Permutations

Arrangement where order matters.

nPr = n!/(n−r)!

Combinations

Selection where order does not matter.

nCr = n!/[r!(n−r)!]

Repetitions

Counting changes when objects can repeat. Identify whether repetition is unrestricted or constrained before choosing the formula.

Binomial Coefficients

Coefficients in binomial expansions are written as nCr.

(x+y)ⁿ = Σ C(n,r)xⁿ⁻ʳyʳ.

Binomial & Multinomial Theorems

Binomial expands two terms; multinomial generalizes the expansion to more than two terms.

Inclusion–Exclusion

Used to avoid double-counting overlapping sets.

|A∪B| = |A|+|B|−|A∩B|.

Pigeonhole Principle

If more objects are placed into fewer boxes, at least one box contains more than one object.

MODULE V • Graph Theory

Graphs & Trees

Basic Concepts

A graph consists of vertices and edges. Know degree, adjacency, paths, cycles and connectedness.

Isomorphism & Subgraphs

Graph isomorphism preserves adjacency structure. A subgraph is formed using selected vertices and/or edges of a graph.

Trees & Properties

A tree is a connected graph with no cycles. A tree with n vertices has n−1 edges.

Spanning Trees

A spanning tree contains all vertices of a connected graph and is itself a tree.

Directed & Binary Trees

Directed trees use oriented edges. A binary tree has at most two children for each node.

Planar Graphs & Euler Formula

For a connected planar graph, Euler's formula is V−E+F=2.

Multigraphs & Euler Circuits

A multigraph may contain multiple edges between the same vertices. An Euler circuit uses every edge exactly once and returns to its start.

Hamiltonian Graphs

A Hamiltonian cycle visits every vertex exactly once and returns to the starting vertex.

Chromatic Numbers

The chromatic number is the minimum number of colors needed to color vertices so adjacent vertices receive different colors.

EXAM PRACTICE

⭐ Important Questions

Module I: Construct truth tables; prove tautology and logical equivalence; convert propositions into normal forms.
Module II: Test validity using rules of inference; solve quantifier/predicate problems; identify relation properties; draw Hasse diagrams and solve lattice problems.
Module III: Find inverse/composition of functions; solve recursive-function problems; verify algebraic structures; prove subgroup/homomorphism/isomorphism properties.
Module IV: Solve permutation and combination problems; handle repetition/constrained repetition; apply binomial/multinomial theorem; solve inclusion–exclusion and pigeonhole problems.
Module V: Identify graph properties; solve tree/spanning-tree problems; use Euler formula; determine Euler/Hamiltonian properties and chromatic numbers.

⚡ Quick Revision

Logic: p→q is false only for T→F. Relations: equivalence = reflexive + symmetric + transitive. Group: associative + identity + inverse + closure. Counting: order matters → permutation; order doesn't matter → combination. Tree: connected + acyclic, E=V−1. Planar connected graph: V−E+F=2.
