About StudentHub

StudentHub is a free, mobile-friendly collection of calculators and study utilities designed to make everyday student tasks faster.

What we provide

CGPA, SGPA, attendance, percentage, marks, exam countdown, study timer and other practical tools.

We plan to add more useful tools and student resources over time.

StudentHub V8: favorites, sharing, copy-result controls and student-focused tools.

V10: Added a Student Power Pack with GPA, attendance, exam-goal, subject-priority, Pomodoro and budget-planning tools.

V11: StudentHub now uses Supabase Auth for optional real email/password accounts. Passwords are handled by the authentication service, not stored by StudentHub.

V12: Added a cloud-synced StudentHub dashboard for favorites and Student Power Pack data. User data is protected with Supabase Row Level Security.

V13: Added focused calculator and study-tool resource pages, stronger internal linking, improved page metadata and a refreshed sitemap for search-engine discovery.
